Linux Server Homelab
Overview
I built a Linux server from scratch in a virtual machine using Ubuntu Server. I configured remote access, created users and permissions, secured the server with a firewall, and enabled system updates.
This project helped me understand how real Linux servers work and how system administrators and cybersecurity professionals secure infrastructure.
